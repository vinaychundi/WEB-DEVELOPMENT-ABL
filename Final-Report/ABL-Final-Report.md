## Selected case studies
1. **Case Study 20 – Restaurant and Cafe Website:** restaurant information, navigation, menu items, weekly special, opening hours and contact details.
2. **Case Study 21 – Online News Portal:** category navigation, featured story, article cards, quick briefing and newsletter information.
3. **Case Study 26 – College Fest Management Website:** technical and cultural event cards, festival schedule and campus information.

## Objective
To apply the concepts from the supplied Web Development syllabus (Units I, II and III) by designing and building three informative, responsive static websites.

## Technologies
- HTML5 for page structure, semantic sections, headings, paragraphs, navigation links and metadata.
- CSS3 for selectors, classes, typography, colors, backgrounds, borders, spacing, box model and responsive layouts.

## Syllabus coverage
The projects demonstrate HTML basics and elements; CSS syntax and rulesets; class attributes; text alignment and color; font family and size; text decoration and style; height and width; background properties; border, padding and margin; lists and hyperlinks; viewport settings; UI design principles; visual hierarchy; color theory; typography; accessibility considerations; and a mobile-first design approach.

## Project implementation
Each project is in its own folder and contains:
- `index.html` – webpage structure
- `style.css` – styling and responsive layout
- `screenshots/desktop-preview.svg` – visual screenshot preview

The pages are static educational demonstrations and intentionally do not use JavaScript, a database or backend services. Contact information, prices, schedules and event descriptions are illustrative sample content.

## Conclusion
The three projects demonstrate how HTML structure and CSS styling can create informative, visually consistent and responsive websites while remaining within the requested syllabus scope.
